# SHOP_Logger

EmpoweringWOMEN（みんまちSHOP）で来場者の行動ログを取るためのツールです。
フォルダごとに独立しているので、片方を削除してももう片方はそのまま動きます。

| フォルダ | 内容 | GAS / スプレッドシート（Drive: SHOP_Logger0.0/） |
|---|---|---|
| [`stamp-rally/`](stamp-rally/) | 案① QRスタンプラリー＋景品引換（来場者がQRを読み取る） | `stamp-rally/` |
| [`booth-tap-logger/`](booth-tap-logger/) | 案③ ブース記録＋景品引換（スタッフが来場者のマイQRを読み取る） | `booth-tap-logger/` |

セットアップ手順や仕様は、各フォルダの README.md を参照してください。
